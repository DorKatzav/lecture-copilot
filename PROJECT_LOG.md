- **Incident — memory.** First fixture replay: pressure "warning", swap +11.2 GB; second: +7.7 GB, the Ollama runner (`llama-server`) at 10.1–18 GB for an 8.3 GB model. Root cause (reproduced, `eval/m1.json` `prompt_cache`): Ollama 0.34.2 runs models in llama-server, which keeps the KV state of every distinct prompt in host RAM up to 8 GiB (`--cache-ram`, default 8192).
