PLAN_HE · תוכנית עבודה · 22.9.2026

Lecture Copilot — שבעה שלבים עד 18.10

התוכנית האנגלית המלאה (חוזים, שערים, צעדים ידניים) ב-PLAN.md. הדף הזה הוא מה שאתה צריך לדעת: מה נבנה בכל שלב, מה מוכיח שהוא גמור, ומה אתה עושה ידנית.

שיטת עבודה: כמו Northwind / FunnelIQ / HarborValeענף + PR לכל שלבדו"ח עברי + Obsidian אחרי כל שלב

איך עובדים (מה שכבר עבד בפרויקטים הקודמים)

  • Design first, code second — האפיון (DESIGN_HE.html) מאושר. הפתעה = החלטה ממוספרת ב-PROJECT_LOG.md עם חלופות ומחיר, לא תיקון שקט.
  • שלב = ענף = PR = שער. python scripts/gate.py --m N חייב להדפיס GATE M<N>: PASS k/k. בדיקה שלא ראו אותה נכשלת היא קוד לא בדוק — שוברים בכוונה ומראים שהשער תופס.
  • בונים רק את השלב הנוכחי. חריגה של יום = הפריט הבא בסולם הוויתורים נופל, בלי דיון: Zoom → LangGraph → re-rank → flashcards → mlx → digest.html.
  • טרמינל באנגלית, דוחות בעברית. אחרי כל שלב: docs/reports/M<N>_HE.html נפתח בדפדפן, עדכון ב-Obsidian, ואתה מאשר את ה-merge.
  • מספרים מיוצרים, לא מוקלדים. Eval מ-eval/results.json, עלות והשהיה מטבלת decisions.
  • ההקלטות קדושות. לא נערכות, לא עולות ל-GitHub.
